# FTSE 100 Live Stock Tracker

This repository contains two Python scripts to track live FTSE 100 stock movements using the Yahoo Finance API. This project was featured in my YouTube tutorial.

## Files Included
* **`FTSE_100_Stock_Tracker.py`**: A lightweight command-line (terminal) version.
* **`FTSE_100_V2.py`**: A graphical user interface (GUI) version built with Tkinter that highlights massive market movers.

## How to Install and Run
1. Clone or download this repository to your machine.
2. Install the required libraries by running this command in your terminal:
   pip install -r requirements.txt

3. Run your preferred version by typing one of these commands:
   python FTSE_100_Stock_Tracker.py
   
   OR
   
   python FTSE_100_V2.py
